ACTIVE DEVELOPMENT

NEXUS

Universal Compilation Engine

A compiler platform capable of translating source programs into platform-independent intermediate representations, then targeting native code across Linux, Windows, and macOS. Encompasses lexing, parsing, AST generation, semantic analysis, IR design, and a custom VM execution layer.

// COMPILER PIPELINE
SOURCE Lexer Tokenisation
→
FRONTEND Parser Grammar + recovery
→
ANALYSIS AST + Sema Type checking
→
IR NEXUS IR Custom + LLVM
→
BACKEND Codegen x86 · ARM · WASM
→
OUTPUT Native bin Linux · Win · macOS
// KEY ENGINEERING DECISIONS
  • Why LLVM? Mature optimisation passes and multi-target backend — avoids reinventing register allocation and instruction selection from scratch.
  • Why a custom IR? LLVM IR is too low-level for early analysis passes; NEXUS IR sits above it, preserving type and scope information longer.
  • Parser error recovery — panic-mode synchronisation on statement boundaries keeps parsing after syntax errors instead of aborting.
  • Manual memory management — arena allocators per compilation unit; no GC overhead during compile time.
