NEXUS

Experimental Compiler Platform (C++ / LLVM)

An experimental compiler engine built from first principles to translate custom source programs into intermediate representations, targeting native code across Linux, Windows, and macOS. Encompasses lexing, parsing, AST generation, semantic analysis, IR design, and VM execution. Demonstrates deep low-level engineering capabilities behind my frontend craftsmanship.

// COMPILER PIPELINE & ARCHITECTURE
// KEY ENGINEERING DECISIONS
  • Why LLVM? Mature optimisation passes and multi-target backend — avoids reinventing instruction selection from scratch.
  • Why custom IR? NEXUS IR sits above LLVM, preserving high-level scope and type info longer for front-end analysis.
  • Parser error recovery — panic-mode synchronisation keeps parsing after syntax errors instead of aborting.
  • Manual memory management — arena allocators per compilation unit for zero GC overhead.
